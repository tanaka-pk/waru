# waru

旧個人ホームページの保存・移行用リポジトリです。

旧サイト：
`http://www.t3.rim.or.jp/~waru/`

長年 RIMNET 上で公開してきたホームページを保存し、
今後も閲覧できるようにするため、GitHub への移行を進めています。

## 現在の状況

移行準備中です。

RIMNET のサーバーから元のHTML・画像などを取得し、
できるだけ当時のサイト構成や内容を維持したまま保存する予定です。

## 移行方針

- 元のHTMLや画像などを可能な限りそのまま保存する
- 元サイトのディレクトリ構造をできるだけ維持する
- 原本の内容を不用意に変更しない
- GitHub Pages で閲覧できる形に整える

移行完了後、公開先のURLをここに記載します。
